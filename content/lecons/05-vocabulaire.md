## Quatre thèmes, trente-deux mots

Le vocabulaire de départ est tiré du dictionnaire lui-même, regroupé par thème :

- **salutations** — merci, salut, adieu, bienvenue, pardon, oui, non ;
- **famille** — père, enfant, frère, sœur, fils, fille, mari, femme ;
- **marché** — marché, argent, acheter, vendre, prix, panier, sel, poisson, maïs, igname ;
- **temps** — jour, matin, soir, nuit, mois, an, aujourd'hui.

Les nombres ne figurent pas : le lexique numérisé n'en contient aucun. Les thèmes s'enrichiront
quand la base sera complétée.

## Comment fonctionnent les exercices

Deux sens de question, tirés au hasard :

- **français → éwé** : le mot français s'affiche, quatre traductions sont proposées ;
- **éwé → français** : l'inverse.

Les mauvaises propositions sont prises dans des mots de même nature grammaticale, pour éviter de
pouvoir deviner en éliminant les catégories.

## La porte qualité

Seuls les mots **relus** entrent dans les exercices. Un apprenant ne doit jamais mémoriser une
erreur de numérisation : tant qu'un mot n'a pas été vérifié, il reste consultable dans le
dictionnaire mais absent du quiz.

C'est pourquoi un thème peut afficher « aucun mot relu pour l'instant ». La liste s'ouvre au fur et
à mesure des relectures.

## La progression

Chaque mot vu passe dans une des trois boîtes : une bonne réponse le fait monter, une erreur le
renvoie dans la première. Les mots de la boîte 1 reviennent en priorité.

La progression est stockée **dans ton navigateur**, pas sur un serveur : aucun compte, aucune
donnée envoyée. Vider les données du site remet les compteurs à zéro.

> Un mot relu, quatre propositions, trois boîtes. Rien de plus : la répétition fait le reste.
